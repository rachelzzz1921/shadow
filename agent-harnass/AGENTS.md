# Agent Harness Workspace

This workspace is for reusable agent-harness research and operating patterns.

Start here:

- Read `agent.md` for the engineering playbook.
- Read `docs/harness/reuse-summary.zh-CN.md` for the Chinese quick map from research sources to reusable harness modules.
- Read `docs/harness/source-map.md` before changing claims or references.
- Read `docs/harness/expert-index.md` when tracing provider experts, authors, papers, and reusable patterns.
- Use `skills/harness-maintenance/SKILL.md` when refreshing research, adding a new provider pattern, or converting a workflow into a reusable skill.

Working rules:

- Treat harness work as system design, not one-off prompt writing.
- Preserve the loop: goal, actor, environment, feedback, memory, and stop conditions.
- Prefer primary sources for OpenAI, Google/DeepMind, Anthropic, and research-paper claims.
- Keep provider-specific claims cited and dated.
- When adding a new workflow, include acceptance checks and rollback or escalation paths.
