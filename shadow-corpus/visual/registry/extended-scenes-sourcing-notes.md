## 七大补充领域

### 1. 四季气候 FX（前包只有雨，现在补全四季）

前包仅有 OGA Rain（CC0）覆盖雨天。六域 Agent 里大量场景需要**时间流逝的视觉语言**——年份推移不能每次靠字幕，季节变换是最自然的载体。

**Seliel the Shaper / Mana Seed 系列**（主力新增）  
https://seliel-the-shaper.itch.io/

| 包 | 用途 | 价格 |
|----|------|------|
| Weather Effects | 雪/雨两强度+落叶+闪电 overlay | $6 |
| Autumn Forest | 秋日地形+透明落叶 autotile | 低价 |
| Winter Forest | 冬雪地形+枯树 | 免费/低价 |
| Summer Forest | 夏季茂密绿林 | 需核实 |
| Spring Forest | 春日嫩绿（从官方集合确认链接） | 需核实 |
| Arctic Woodland | 极地冰雪，比冬林更严酷 | 付费 |
| Character Base | 主角基础动画（free，商用可） | 免费 |
| Farmer Sprite System | 农村劳作 NPC（free，商用可） | 免费 |
| RPG Starter Pack | 免费起步底图 | 免费 |

所有 Mana Seed 资产使用统一的 **Mana Seed User License**：商用可，不可再分发/出售单个资产。风格是16位 SNES 风格，16x16 tiles，与 Seliel 系列完全兼容。

**为什么选 Mana Seed 做四季主力**：
- 同一系列所有地形风格一致，不同年份切换季节不会漂移
- Weather Effects 与地形是同作者，overlay 已经匹配好色板
- Character Base 免费可商用，主角可以直接在四季地形上走动

**Snow City**（免费，Free Game Assets）  
https://free-game-assets.itch.io/snow-city-tileset-pixel-art  
和 Gandalf City 互补，提供**城市场景的冬季变体**，不需要整套换底图。

**Icarus Studios Seasonal Forest / Maru Forest Fall Pack**  
额外的秋日和四季自然补充；风格不同于 Mana Seed，适合做风格对比或备选。

### 2. 乡镇/农村（亲情老家、自我成长离家）

前包有 Kenney Tiny Town（CC0 抽象小镇）和 Sprout Lands（自然农场），但缺少**有生活感的中国式农村外景**。

**Cainos 系列**  
- Pixel Art Top Down - Basic（免费，商用可改）：农田/草地/泥路，最写实的乡间地形  
- Pixel Art Top Down - Village（$39.99，商用可改，禁再分发）：带建筑的完整村镇  
- https://cainos.itch.io/

**Sanctumpixel Village**  
https://sanctumpixel.itch.io/village-top-down-pixel-art-tileset  
RPG 风格村庄，授权需核实；作为 Cainos 的风格备选。

使用原则：Cainos Basic 做地形底层，Cainos Village 做建筑层，Kenney Tiny Town 做抽象章节地图——三者叠加形成"小镇→村边→田野"的完整城乡对比。

前包的户外场景主要是城市街景（Reakain/Gandalf）。约会公园、深夜独处仰望星空这类**非街道户外**缺素材。

https://free-game-assets.itch.io/free-green-zone-tileset-pixel-art  
城市公园：长椅、草坪、喷泉。同一公园长椅可在不同年份反复使用，表达时间流逝。

**夜空系列**（两款互补）
- Starry Night Parallax (Shiroze)：https://shiroze.itch.io/starry-night-parallax-background
- Night Sky BG 4 Variants (ChrisPpop)：https://chrisppop.itch.io/night-sky-pixel-art-background  
  深夜失眠/独处场景替代室内背景，产生内省感；异地恋视频通话背景。

**Free Sky Backgrounds**（免费）  
https://free-game-assets.itch.io/free-sky-with-clouds-background-pixel-art-set

https://feyza5.itch.io/cozy-library
