# Visual 在 Shadow 体验里的位置

## 三种呈现（A/B/C）

| 类型 | 是什么 | 触发时机 |
|------|--------|----------|
| **A** 日常 loop | 2–4 帧小动画（吃饭、失眠、撕纸） | 该年 quiet 回放时角标/背景循环 |
| **B** 特殊场景 | 每年 1 张主景 + 轻动效 | 进入该年卡片时全屏/主视觉 |
| **C** pivotal 短片 | 3–5 步 sequence | 介入弹窗前后、final 前 |

## 用户流程映射

```
填写 profile
    → [C 短] 开场：教室最后一排（可预览）
Persona / Beats
    → [B] 七年节奏条（缩略特殊场景）
逐年 Year
    → [B] 该年特殊场景
    → [A] 日常 loop（quiet 年为主）
    → [C] pivotal：介入前 sequence → 弹窗 → 介入后 sequence
Final
    → [C] 收束短片 + [B] 邮局定帧
Dialogue
    → [A] 轻微 idle 动画，不抢文字
```
