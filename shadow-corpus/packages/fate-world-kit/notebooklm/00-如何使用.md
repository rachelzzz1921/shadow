# NotebookLM → Shadow World 语料：使用说明

## 准备

1. NotebookLM 笔记本已收录 **2006–2026（或你有的近 20 年）** 中国大陆资料：统计公报、年鉴、媒体报道、文化年表、教育就业政策等。
2. **不要**让模型用训练记忆补全；只引用笔记本内可见内容。
3. 建议 **按年分批**（一次 1 年），避免输出被截断。

## 工作流

```
NotebookLM（你的 20 年资料）
    ↓ 粘贴 01-ENRICH-PROMPT-按年.md（改 YEAR）
    ↓ 得到 JSON patch
    ↓ 保存为 world/data/notebooklm-import/2018.patch.json
    ↓ node scripts/import-notebooklm-patch.mjs
    ↓ npm run validate
    ↓ 可选 npm run seed
```

## Patch 文件格式

`world/data/notebooklm-import/2018.patch.json`：

```json
{
  "calendar_year": 2018,
  "notebooklm_note": "笔记本名称或批次说明",
  "summary": "可选，覆盖或追加",
  "social_mood": "可选",
  "atmosphere": { "gdp_trillion_cny": 90.03 },
  "pop_culture": ["我不是药神", "..."],
  "sources": ["https://...", "..."],
  "macro_events": [ { "category": "economy", "title": "...", "detail": "...", "source_url": "...", "weight": 1.0, "sensitivity": "low", "tags": [] } ],
  "micro_events": [ { "category": "school", "scenario": "academic", "text": "...", "weight": 1.0, "can_pivot": false, "sensitivity": "low", "tags": [] } ]
}
```

- 只需填 **要新增或替换** 的字段；`import-notebooklm-patch.mjs` 会与现有 `{year}.json` **合并去重**（按 title / text）。
- `macro_events` 必须带可核查的 `source_url`（笔记本内引用的 URL 或文献名写在 detail 末尾）。
- `micro_events` 必须带 `scenario`（六域之一）。

## 六域 micro 写什么

| scenario | 个人尺度际遇示例 |
|----------|------------------|
| family | 父母期待、春节、愧疚、汇款 |
| love | 分手、相亲、异地 |
| friendship | 室友、圈子散了、散伙饭 |
| academic | 高考、考研、复读、转专业 |
| career | 就业、裁员、考公、996 |
| self_growth | 迷茫、身份、遗憾、心理咨询 |

每条 **20–60 字**，第二人称或中性，像「那一年个人可能遇上的事」。

## 若 NotebookLM 输出不是纯 JSON

1. 要求它「只输出一个 ```json 代码块，不要其它文字」。
2. 复制代码块到 `.patch.json`，用 `node -e "JSON.parse(require('fs').readFileSync('...'))"` 验证。
3. 失败则追问：「请修复 JSON 语法，保持字段不变」。

## 按域补充

若某年 **学业域 micro 仍偏少**，用 [`02-ENRICH-PROMPT-按六域.md`](02-ENRICH-PROMPT-按六域.md) 再跑一轮，只追加 `micro_events`。
