# Shadow Demo — Runnable Example

平行人生叙事 demo 的可运行实现，属于 Shadow Harness 框架的 `example/` 部分。

## Run

```bash
npm install
npm run dev
```

或从仓库根：

```bash
npm install:demo
npm run dev
```

## Test

```bash
npm test
```
